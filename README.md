# 🎪 Festival Flask Project

A simple web application built with **Flask** to present a fictional festival event.  
The project includes pages for **home**, **categories**, and **speakers**, using dynamic data passed from Python to HTML templates.

Ideal for practicing:
- Flask routing  
- Jinja2 templates  
- Passing data to the frontend  
- Basic project structure  

---

## 🚀 Features

- Home page with festival introduction
- Categories page displaying event topics
- Speakers page with name, role and descriptions
- Responsive layout using HTML + CSS
- Organized Python structure with multiple modules

---

## 🛠 Technologies Used

- **Python 3**
- **Flask**
- **Jinja2**
- **HTML5**
- **CSS3**
- Bootstrap (optional, if used)
